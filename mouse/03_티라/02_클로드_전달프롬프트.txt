티라 한 캐릭터의 마우스 액션 「먹는 건가? …딸꾹, 뿍!」을 구현해줘.
이 작업은 로그인 인트로가 끝나 친구들이 작아져 로그인 화면에 자리 잡은 이후의 반응이다. 기존 등장·환영·거꾸로 팻말·불꽃 인트로는 유지하고, 다른 캐릭터와 타자 입력 모션은 이번에 새로 만들지 않는다.

[캐릭터의 핵심]
티라는 팔이 없다. 새 팔·손을 붙이거나 손으로 무엇을 들게 하지 않는다. 작은 점눈, 다섯 이빨의 멍한 얼굴, 몸·꼬리가 한 박자 늦게 따라오는 덤벙거림을 살린다. 커서를 신기한 먹이처럼 바라보다 몸을 기울이고, 딸꾹질로 짧게 불을 뿜은 뒤 자기가 놀라 눈을 질끈 감는다. 다시 멀뚱한 얼굴로 돌아오는 것이 웃음 포인트다.
그림체는 티라 원본 그대로 단순하게 유지한다. 과장된 연출만 사용하고 주름·눈썹·콧구멍·흰자·눈 하이라이트를 추가하지 않는다.

[현재 코드와 파츠 먼저 확인]
tira_v3/tira_v3.json, rig.json, README.md, intro/intro-cast.js와 실제 로그인·모션 에디터 연결 코드를 읽어줘. 오래된 tira/나 tira_v2가 아닌 현재 tira_v3를 기준으로 한다.
현재 눈·입은 headImg에 합쳐져 있고 자동 follow 대상이 없다. 눈이 별도 파츠라고 가정하면 작동하지 않는다. 이번에 얼굴 내부 바탕과 눈·입 레이어를 추가한다.
현재 stage는 400×400, rig pivot=(640,1121), rest=(200,385), scale=0.3. sway와 head 그룹이 분리되어 있고 head pivot=(603,650)이다. 몸통은 그대로 두고 머리만 기울일 수 있다.

[추가 이미지 네 장]
01 얼굴바탕: 원래 눈·입을 덮는 황갈색 바탕. 얼굴 안쪽에만 사용한다.
02 눈_점눈공용: 회갈색 점눈 한 개. 좌우 두 번 재사용한다.
03 입_기본다섯이빨: 원래처럼 다섯 이빨이 있는 입.
04 입_호기심: 작은 회갈색 ㅇ 입.
얼굴바탕은 원본 색값의 SVG 마스크를 PNG로 렌더링한 파일이며, 나머지 세 PNG는 내장 이미지 생성 출력 그대로다. 원본 머리 비트맵은 편집하지 않았다. 추가파츠_조립정보.json의 실제 캔버스·source_rect와 guide_draw_rect를 사용해 기존 1254 좌표계에 조립한다. 파일 전체를 같은 자리에 단순히 겹치면 맞지 않는다.

[얼굴 조립 — 가장 중요한 부분]
기존 headImg 0을 그대로 그린다. 그 위에 01 바탕을 얼굴 내부 clip 안에서만 덮고, 새 눈 두 개와 입을 얹는다. 원래 머리 외곽선·흰 뼈깃·목·아랫몸통 폭은 새 이미지로 교체하지 않는다.
얼굴바탕 PNG에는 face_cover_clip_polygon과 가장자리 3 원본 px의 부드러운 경계가 이미 적용되어 있다. 같은 1254 좌표에 그대로 그리며 별도로 한 번 더 마스크를 씌울 필요는 없다. SVG 대안을 직접 쓰거나 바탕을 재구성할 때만 같은 폴리곤과 부드러운 경계를 재현한다. 원래 눈과 입이 완전히 가려지는지 확인한다. 바탕을 넓혀 원래 외곽선을 덮어 버리지 않는다.
새 눈 중심은 왼쪽 (517,446), 오른쪽 (679,446), 크기 44×42 정도. 새 기본 입 중심은 (600,571), 414×120을 시작값으로 사용한다. 호기심 입도 같은 중심에 둔다. 정확한 값은 JSON을 참고한다.
새 바탕·눈·입은 head 자식이며 headImg 다음, collar 이전 순서로 그린다. 입은 follow를 끈다.
기존 뜨거워 머리(headImg 1), 뒤보기, 물기, 기존 인트로에서는 새 바탕·눈·입을 모두 숨긴다. 기본 머리 위에 C의 눈만 얹거나, 기존 >< 머리 위에 점눈을 남기지 않는다. 이번 마우스 액션에서는 팻말·입 앞가림 mask도 숨긴다.
기존 인트로 데이터와 headImg 원본 바이트는 보존한다. 새 파츠의 기본 op는 0으로 하고 로그인 마우스 상태에서만 켜는 등 기존 인트로와 충돌하지 않는 구조를 사용한다.

[기본 시선 추적]
양쪽 점눈을 같은 방향으로 최대 원본 10px 정도 이동시킨다. 기본 0.3배 무대에서 약 3px다. 실제 표시 배율에 맞게 비례 적용한다.
눈이 먼저 반응하고 머리는 약 0.1초 늦게 최대 좌우 2도만 기울인다. 몸통은 이동하지 않고 꼬리는 2~3도 정도로 더 늦게 반응한다.
캐릭터의 실제 화면 좌표를 사용하고 시간 기반 보간으로 이어줘. 기존 렌더링 루프가 있으면 통합하고 mousemove마다 새 타이머나 rAF를 쌓지 않는다.

[시작 조건]
티라의 화면 경계 및 주변 약 0.25H에서 커서가 0.85초 머무르면 시작. H는 실제 표시 높이다. 약 14 CSS px 넘게 이동하면 머무름 시간을 다시 센다.
시작 시 커서 방향을 고정한다. 좌우 가운데 작은 구간에서는 직전 방향을 유지하고 직전 방향이 없으면 왼쪽을 선택한다.
약 2.5초 한 번 재생한 뒤 계속 머물러도 반복하지 않는다. 영역 이탈·재진입이 필요하고 시작 간격은 최소 6초다.

[표정 — 세 종류만]
A 기본: 원래 정면 머리 + 내부 바탕 + 점눈 두 개 + 다섯 이빨 입.
B 호기심: A와 같은 바탕, 점눈 sx=sy 약 1.1, 작은 호기심 입.
C 뜨거워: 기존 headImg 1. 새 얼굴 조각 모두 숨김.
눈·입과 머리 모드를 같은 시점에 바꾼다. 긴 크로스페이드로 원래 눈과 새 눈이 겹치지 않게 한다. C 이후 멋쩍은 추가 표정을 따로 만들지 말고 A의 멍한 얼굴과 멈칫으로 표현한다.

[타임라인 — 머무름 조건 충족 후]
0.00~0.30초: A→B. 먹는 건가? 하는 느낌으로 머리를 커서 쪽 최대 3도 기울인다.
0.30~0.75초: B 유지. sway 최대 2도, head 추가 최대 3도. 꼬리는 0.1초 늦게 반대로 6도. 먼 쪽 발만 y=-8px·회전 4도 이내로 작게 꼼지락. 반대 발은 바닥을 유지하고 몸 전체가 좌우로 이동하거나 점프하지 않게 한다.
0.75~0.95초: B 유지. 딸꾹질 직전 잠깐 들숨. 몸 세로 1.015·가로 0.985 이내, 머리 y=-4px 정도 먼저 움찔. 수치는 원본 좌표 변화량이며 기존 rest에 더한다.
0.95~1.17초: C로 동시 교체하고 짧은 불꽃. 작은 불 0.95~0.99, 축소한 큰 불 0.99~1.10, 작은 불 1.10~1.17, 이후 숨김. 머리가 살짝 뒤로 젖혀지고 꼬리는 늦게 움찔한다.
1.17~1.55초: 불은 끈 상태에서 C 유지. 약 0.15초 멈칫하고 돌아오기 시작한다.
1.55~2.50초: A로 동시에 복귀. 몸이 먼저 바로 서고 꼬리가 마지막 작은 반동 후 정착. 정면으로 짧게 멀뚱히 보다가 현재 커서 추적으로 자연스럽게 연결한다.
이후: A로 따라보기. 같은 자리에서 다시 시작하지 않는다.

[불꽃]
기존 fire 이미지 0=t3_fire12, 1=t3_fire13b를 재사용한다. 이미 큰 불은 굵고 가운데 노란 만화 불꽃이므로 새 불 그림을 추가하지 않는다.
큰 불은 rest 기준 sx=0.60, sy=0.65 정도로 시작한다. head 자식, 현재 fire pivot/rest=(402.11,568.81)을 유지하고 뿌리를 기준으로 줄여 입에서 떨어지지 않게 한다.
커서가 오른쪽이라고 불을 오른쪽으로 반전하지 않는다. 현재처럼 화면 왼쪽 입 모서리에서 나온다. 캐릭터 전체 그림도 반전하지 않는다.
로그인 폼이나 옆 친구를 가리면 먼저 크기·각도를 더 줄이고, 공간이 없으면 불을 생략하고 딸꾹질만 보여준다. 불꽃을 영역 경계에서 잘라 단면이 보이게 하지 않는다. 소리·글자 ‘딸꾹’·효과음 말풍선은 추가하지 않는다.

[중도 취소·우선순위]
커서가 떠나면 현재 자세에서 0.35~0.5초 동안 A로 복귀. 불이 나오기 전이면 취소하며, 이미 나왔다면 0.08초 내에 먼저 끈다. 남은 불꽃·딸꾹질을 강제로 재생하지 않는다.
액션 중에는 시선 자동 추적과 자동 깜빡임을 잠시 중단하고 시작 방향을 유지한다. C가 끝나 A로 바뀔 때 현재 커서 추적으로 연결한다.
길통이·차로차로와 영역이 겹치면 가장 가까운 한 캐릭터만 시작한다. 다른 캐릭터가 이미 동작 중이면 갑자기 끊지 말고 티라는 대기한다. 이번 작업 때문에 다른 친구 모션을 새로 만들지 않는다.
인트로·입력 중·비밀번호·로그인 전환은 마우스보다 우선한다. 비밀번호 포커스 중에는 시선 추적을 끄고 기존 프라이버시 연출이 있으면 우선한다. 타자 키별 반응이나 새 비밀번호 모션은 이번에 만들지 않는다.
폼 클릭을 가로채지 않도록 표시 레이어의 pointer-events를 처리한다. 모션 감소에서는 몸 흔들기·불·딸꾹질을 생략하고 작은 눈 추적만 쓴다. 터치 기기에서 마우스 액션을 자동 실행하지 않는다.

[검수하고 보고]
1. 원본 정면과 A를 나란히 비교. 머리·뼈깃·몸통 폭 유지, 점눈 두 개·이빨 다섯 개, 원래 눈·입 잔상과 바탕 색 경계가 없어야 함.
2. A/B/C 전환을 0.25배로 재생. 점눈이 >< 위에 남거나 입이 두 겹이 되지 않아야 함.
3. 최대 눈 이동·머리·몸 기울기에서 얼굴 밖 이탈, 목 틈, 발 접지, 프레임 잘림 확인.
4. 불의 입 연결·크기·주변 가림과 시작 전/중간 이탈을 확인.
5. 빠른 이동, 재진입 반복, 창 밖 이탈, 창 크기 변경, 다른 친구와 반응 영역 겹침 확인.
6. 기존 인트로의 거꾸로 팻말·머리 회전·불꽃이 유지되는지 확인.
수정 파일, 모션 에디터 수동 재생 방법, 실제 확인한 항목과 남은 검수 항목을 알려줘.

다음 캐릭터는 사용자가 ‘다음’이라고 하면 별도로 진행한다.
