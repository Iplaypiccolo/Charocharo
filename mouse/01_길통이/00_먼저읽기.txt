길통이 마우스 액션 — 어? 뭐지?

1. 01_길통이_마우스액션_세부콘티.md에서 동작과 타이밍을 확인하세요.
2. 조립미리보기.html을 브라우저로 열면 기존 파츠와 추가 파츠를 겹친 A/B/C 포즈를 볼 수 있습니다. 인터넷이 필요하지 않습니다.
3. 추가파츠 폴더의 PNG 네 장이 이번 추가 이미지입니다. 기존 눈·눈썹 등은 사이트 파츠를 재사용합니다.
4. 02_클로드_전달프롬프트.txt 전체를 복사하고 이 압축파일을 함께 전달하세요.
5. 추가파츠_조립정보.json은 새 이미지의 그림 영역과 기존 파츠 좌표를 매핑하는 자료입니다.

PNG 규격: 1254×1254 / RGBA / 배경 투명.
현재 길통이의 실제 원본 좌표에 맞춘 규격입니다. 원본 PNG 전체를 같은 자리에 단순 오버레이하는 파일이 아니며, JSON의 source_rect→guide_draw_rect 매핑이 필요합니다.

포함된 표정: A 기본 / B 호기심 / C 생각중.
추가 그림: 작은 ㅇ 입 / 생각하는 입 / 턱 가까이 올린 왼팔 / 물음표.

완료한 확인: 이미지 크기·알파 채널 및 기존 파츠와 세 가지 정적 포즈 조립.
다음 구현 단계의 확인: 사이트 실제 연속 동작, 팔 전환, 커서 이탈과 재진입, 입력 화면과의 상태 우선순위.

이번 작업은 길통이만 포함합니다. 다른 캐릭터와 타자 입력 모션은 포함하지 않았습니다.
