길통이의 로그인 화면 마우스 액션만 구현해줘. 이번에는 다른 캐릭터나 타자 입력 모션으로 범위를 넓히지 말아줘.

[장면 맥락]
로그인 인트로에서 친구들이 정면으로 달려와 환영하고, 슬로우 장면과 폭죽이 끝난 뒤 작아져 로그인 화면에 자리 잡는다. 지금 구현할 것은 그 이후의 길통이 마우스 반응이다. 기존 인트로의 그림·연출·캐릭터 배치와 모션은 유지한다.

[우선 확인]
현재 프로젝트의 giltong/giltong.json, giltong/rig.json, giltong/README.md와 로그인·모션 에디터의 실제 연결 코드를 읽어줘. 전달된 정적 가이드는 현재 사이트 파츠와 조립한 참고이며, 실제 프로젝트의 최신 코드 구조를 우선한다.
기존 눈·눈썹·머리·몸통·망토·기본 입·팔다리를 재사용한다. 이번 추가 PNG 4종은 독립 파츠이므로 파일을 통째로 같은 좌표에 겹치면 맞지 않는다. 추가파츠_조립정보.json의 source_rect와 guide_draw_rect를 이용해 기존 1254 좌표계에 조립한다.
기본 원본 좌표계 1254×1254, 기본 stage 400×400, 몸통 scale 0.24. 화면 크기별 배율은 기존 시스템대로 적용한다.

[연출 이름: 어? 뭐지?]
커서를 차분히 따라보다가 가까이 머무르면 작은 ㅇ 입으로 관심을 보이고, 화면 왼손을 입 왼쪽 아래의 턱 가까이 올린다. 머리를 오른쪽으로 갸웃하며 작은 물음표를 띄운 뒤, 한 번만 작게 끄덕이고 기본 자세로 돌아온다. 귀엽고 익살스럽되 계속 부산스럽게 반복하지 않는다.

[마우스 기본 추적]
- 실제 길통이 화면 위치를 기준으로 정규화한다. 페이지의 고정 좌표를 사용하지 않는다.
- 기존 양 눈을 같은 방향으로 최대 원본 12px 정도 이동시킨다. 기존 0.24배 기준 약 2.9px다. 현재 그리기 배율에 맞게 비례 조절한다.
- 눈썹은 눈 이동의 30% 정도만 반응한다. 입의 커서 추적은 끈다.
- 머리 방향 반응은 좌우 최대 2도. 갸웃 동작 중에는 추적 회전을 누적하지 않는다.
- 위치는 시간 기반 보간으로 부드럽게 연결한다. 프레임마다 고정 비율을 곱해 고주사율에서 속도가 달라지는 방식은 피한다. 기존 requestAnimationFrame 루프가 있으면 통합한다.
- 몸과 발 위치는 고정. 머리·눈이 얼굴 경계를 벗어나지 않도록 제한한다.

[시작·재시작 조건]
길통이 경계 및 주변 0.25H 정도 영역에서 0.7초 머무르면 시작한다. 커서가 약 14 CSS px 넘게 움직이면 머무름 시간을 다시 센다. H는 실제 그려진 캐릭터 높이다.
한 번 재생하고 돌아온 뒤 커서가 남아 있어도 반복하지 않는다. 영역 밖으로 나갔다가 다시 들어와야 하며, 시작 간격은 최소 3초다. 반복 출입으로 타이머나 리스너가 중첩되지 않도록 한다.

[표정 세 개]
A 기본: 기존 기본 눈·눈썹·기본 미소.
B 호기심: 기존 기본 눈 sx=1.08, sy=0.96; 양 눈썹 원본 y=-8; 새 mouth_curious.
C 생각중: 기존 기본 눈; 왼쪽 눈썹만 원본 y=-12, 오른쪽은 기본; 새 mouth_thinking.
눈·눈썹·입은 같은 시점에 표정 묶음을 바꾼다. 새 잔선·주름·치아는 추가하지 않는다. 긴 이미지 크로스페이드로 눈이 두 겹 보이지 않게 한다. 눈썹 이동·눈 확대는 80~120ms로 짧게 연결할 수 있다.

[액션 타임라인: 시작 조건 충족 후 약 2.3초]
0.00~0.25: A→B. 어? 하고 관심을 보인다. 머리가 1도 정도 먼저 반응한다.
0.25~0.65: B 유지. 화면 왼팔을 턱 가까이 올린다. 오른팔은 기본. 손이 입을 덮지 않는다.
0.65~1.05: B→C. 머리를 화면 오른쪽으로 6도, 몸은 최대 1도. 망토는 약 0.1초 늦게 따라온다. 물음표를 0.7→1.08→1.0 크기로 작게 등장시킨다.
1.05~1.60: C 유지. 관심 있게 잠깐 본다. 눈만 좁은 범위에서 커서를 따라간다. 질문 효과는 하나만 유지한다.
1.60~2.30: 물음표를 약 0.15초에 걸쳐 지우고, 고개를 세운 후 3도 이하로 작은 끄덕임 한 번. 손을 내리고 약 1.95초에 눈·눈썹·입을 A로 맞춘다. 망토가 늦게 정착한다. 이때 고개·몸 회전은 절대 목표 각도이며 기존 회전에 누적 덧셈하지 않는다.
2.30 이후: A로 커서만 차분히 따라본다. 같은 자리에서 자동 재생하지 않는다.

[중도 취소]
커서가 영역을 벗어나면 어느 단계든 현재 자세에서 0.35~0.5초에 걸쳐 기본으로 돌아온다. 물음표는 0.12초 안에 먼저 지운다. 생각 자세 전이라면 끄덕임을 생략한다. 남은 타임라인을 강제로 끝까지 실행하지 않는다. 창 밖 이탈도 가운데 시선으로 부드럽게 복귀한다.

[팔과 레이어: 반드시 확인]
- 기존 기본 자세는 armL=-48도, armR=+48도다. 부호를 반대로 적용하지 않는다.
- 기존 왼팔 레이어는 머리 뒤라서 올리면 숨는다. 새 arm_chin은 액션 중에만 머리 다음, 눈·눈썹·입 이전에 그리는 오버레이로 사용한다. 기존 armL은 숨겨서 팔이 세 개가 되지 않게 한다.
- 새 팔 부모는 몸통, 어깨 기준은 (520,822). 새 이미지 어깨 기준 (900,1000), 배율 0.20. 변환식은 JSON에 있다. 머리 자식으로 넣어 어깨까지 회전시키지 않는다.
- 팔의 시작과 끝은 기존 팔과 새 팔의 실제 손 위치를 비교해서 연결한다. 볼 옆으로 올리며 머리에 가려지는 짧은 구간에 교체하고, 현재 팔을 갑자기 얼굴 앞에 나타나게 하지 않는다. 이번 자료는 정적 포즈 검수까지이며 연속 전환은 구현 후 느리게 재생해 보정해야 한다.
- 어깨 단면이 도드라지면 몸통의 해당 영역만 앞에 덮는다. 몸통 전체를 머리 위에 그리지 않는다.
- 정적 가이드는 head=+6도에서 손과 입, 물음표와 모자 간격을 확인했다. 실제 작은 크기에서도 서로 겹치지 않도록 확인해줘.

[우선순위와 기존 기능]
인트로 재생, 입력 중, 로그인 전환 중에는 마우스 액션을 중단·복귀시킨다. 비밀번호 칸에서는 마우스 시선을 끄고 기존 프라이버시 동작이 있으면 그것을 우선한다. 이번 작업에서 타자 키별 반응이나 새 비밀번호 모션은 만들지 않는다.
캐릭터 오버레이는 pointer-events:none으로 폼 조작을 막지 않는다. 효과를 위해 로그인 입력을 잠그지 않는다. 터치 전용 기기에서는 커서 머무름 액션을 자동 실행하지 않는다. reduced-motion에서는 기본 시선만 작게 반응하고 손·머리·물음표 튀어오름을 생략한다.
모션 에디터에 테스트용 수동 재생을 기존 방식으로 연결할 수 있다면 연결해줘. 다른 캐릭터 상태나 원래 인트로 데이터를 전역으로 덮어쓰지 않는다.

[검수하고 보고할 것]
1. 기존 기본 자세와 새 A/B/C를 동일 크기에서 나란히 비교. 원래 그림체와 몸·발 위치 유지.
2. 팔 전환을 0.25배 속도로 재생. 세 팔·손 순간이동·입 가림·어깨 틈이 없어야 함.
3. 좌상·우상·좌하·우하 커서, 빠른 이동, 영역 출입 반복, 창 밖 이탈, 창 크기 변경 확인.
4. 0.7초 머무름과 한 번만 재생, 이탈 후 재진입 조건 확인.
5. 인트로·입력·비밀번호·로그인 중 마우스가 끼어들지 않는지 확인.
6. 기존 인트로와 다른 캐릭터가 유지되는지 확인.
7. 실제 확인한 것과 아직 확인하지 못한 것을 나누어 보고하고, 수정 파일 목록과 재생 방법을 알려줘.

먼저 이 범위로 길통이 하나를 완성해줘. 다음 캐릭터는 사용자 확인 후 별도 진행한다.
