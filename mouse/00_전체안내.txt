여섯 캐릭터 마우스 액션 통합 자료

각 캐릭터의 최종 전달 자료를 폴더별로 모았습니다.
이미지·콘티·클로드 전달문·조립 정보의 내용은 변경하지 않았습니다.
개별 ZIP이 중첩되어 있지 않으므로 이 압축파일을 한 번만 풀면 됩니다.
첨다니의 기존 개별 ZIP 오류는 보관된 검수 원본 폴더로 복구했습니다.

폴더와 액션
- 01_길통이: 어? 뭐지? / 추가 PNG 4장
- 02_차로차로: 여기 봐! 파닥·찡긋 / 추가 PNG 3장
- 03_티라: 먹는 건가? …딸꾹, 뿍! / 추가 PNG 4장
- 04_첨다니: 신호가 통했나? 쫑긋·빙긋 / 추가 PNG 2장
- 05_도로덕: 빼꼼…들켰덕! / 추가 PNG 1장
- 06_타로타로: 한쪽 바퀴로 까딱, 엣헴! / 추가 PNG 2장

각 폴더 사용 순서
1. 00_먼저읽기.txt
2. 세부콘티.md와 조립미리보기.html 확인
3. 02_클로드_전달프롬프트.txt를 해당 캐릭터 폴더와 함께 Claude에게 전달
4. 추가파츠_조립정보.json으로 위치·크기·레이어 조립

새 추가 PNG는 총 16장입니다. 조립 미리보기 PNG는 별도로 포함되어 있습니다.
기존 사이트의 몸통 등 재사용 파츠 전체를 새로 담은 자료가 아니라, 추가 파츠와 제작·검수 지시 자료입니다.
실제 연속 모션과 로그인 화면 연동 검수는 Claude 구현 단계에서 진행합니다.
