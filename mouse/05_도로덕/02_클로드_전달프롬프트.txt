도로덕 한 캐릭터의 로그인 화면 마우스 액션 「빼꼼…들켰덕!」을 구현해줘.
이번에는 도로덕만 작업한다. 길통이·차로차로·티라·첨다니의 기존 작업과 로그인 인트로를 유지하고, 타자 입력 모션이나 다음 캐릭터는 새로 만들지 않는다.

[전체 장면 맥락]
친구들이 정면으로 달려와 환영하고, 문구·폭죽이 나오는 슬로우 장면을 거쳐 정렬한 뒤 작아져 로그인 화면에 남는다. 지금은 이 인트로가 끝난 뒤의 마우스 반응이다. 도로덕의 기존 환영 팻말과 인트로 동작은 유지한다.

[캐릭터와 연출]
도로덕은 커서를 유심히 보며 한쪽 눈을 가늘게 뜨고 몸을 빼꼼 기울인다. 들킨 듯 멈칫한 뒤 기존 눈웃음을 짓고 작은 날개로 한 번만 으쓱한다. 마지막에 발끝을 꼼지락하고 기본으로 돌아온다.
부리는 기존 붉은 타원 한 장 그대로다. 입을 벌리거나 안쪽 선·치아·혀를 넣지 않는다. 부리만 별도로 회전·이동·압축하지 않고 몸의 전체 변환만 받게 한다. 새 눈썹이나 머리 관절도 추가하지 않는다.
날개 으쓱은 한 번 들고 천천히 내리는 동작이다. 차로차로처럼 반복 파닥이지 않는다. 물음표·반짝임·말풍선·소리는 추가하지 않는다.

[현재 코드 확인]
doroduck/doroduck.json, rig.json, README.md와 실제 로그인·모션 에디터 연결 코드를 먼저 읽어줘.
현재 body에는 머리가 포함되어 있다. body가 부모 없는 루트이고 pivot=(627,995), rest 위치=(190,332), scale=0.26, stage=400×400이다. 로그인 화면이 별도 배치·배율을 쓰면 그 값을 유지한다.
기존 eyeL/eyeR에는 기본 점눈(index 0), 웃는 눈(index 1)이 있다. beak은 붉은 타원(index 0) 하나다. wingL/R와 footL/R를 재사용한다.
sign, signText, signF, signTextF, wingRf는 이번 로그인 마우스 상태에서 모두 숨긴다. 현재 렌더러가 부모 op를 자식에 자동 적용한다고 가정하지 말고 각각 숨겨줘. 오른날개가 두 장 보이거나 팻말이 따라 나타나면 안 된다.

[추가 이미지]
추가 PNG는 눈_집중공용 한 장이다. 윗변은 수평, 아래는 둥근 낮은 반타원 모양이며 흰자·하이라이트·눈꺼풀 선이 없다. 커서에서 먼 쪽 눈에만 사용한다. 가까운 눈은 기존 기본 점눈을 유지한다.
PNG는 1254×1254 투명 배경이며 내장 이미지 생성 출력 원본을 그대로 복사했다. 추가파츠_조립정보.json의 source_rect→guide_draw_rect로 그리거나 full_png_variant_rect를 기존 images variant에 사용해줘. PNG 전체를 같은 좌표에 단순 오버레이하지 않는다.
기존 눈 그림 중심은 왼쪽 (572,464), 오른쪽 (682.5,464). 새 눈은 같은 중심에 52×30 정도로 넣고 부모는 body다. 한 PNG를 양쪽에 공용으로 사용한다.
source_rect를 target 폭·높이에 맞추는 2축 배치다. Canvas drawImage 9인자 또는 full_png_variant_rect가 동등하게 맞아야 한다. SVG로 미리보면 preserveAspectRatio=none으로 같은 배치를 재현한다.

[기본 커서 추적 — 부리 간격 주의]
양쪽 기본 눈을 같은 방향으로 움직인다. 범위는 원본 좌표 x=-8~+8, y=-6~+1이다. 아래쪽으로는 최대 1px만 움직인다. 기본 눈 그림 아래가 y489, 부리 위가 y493이므로 일반 ±14 범위를 쓰면 부리와 겹친다.
beak의 현재 follow=true를 로그인 마우스 상태에서만 override해 끈다. 원래 부리 위치·크기는 보존한다. 원본 JSON을 전역으로 덮어써 기존 인트로를 바꾸지 않는다.
몸은 눈보다 늦게 커서 방향으로 최대 1.5도만 기울인다. 몸 전체가 좌우로 이동하거나 머리만 따로 회전하는 모션은 만들지 않는다.
캐릭터의 실제 화면 경계로 커서 방향을 정규화하고 시간 기반 보간으로 연결한다. 기존 rAF 루프에 통합하며 mousemove마다 루프나 타이머를 쌓지 않는다.

[시작·방향·재시작]
도로덕 표시 경계 및 주변 약 0.25H에서 커서가 0.8초 머무르면 시작한다. H는 표시 높이이며 약 14 CSS px 넘게 이동하면 머무름 시간을 다시 센다.
시작 순간 방향을 고정한다. 커서가 왼쪽이면 왼눈은 기본, 오른눈은 집중 눈. 오른쪽이면 반대. 가운데 작은 구간에서는 직전 방향을 유지하고 처음부터 가운데면 왼쪽을 선택한다.
한 번 약 2.8초만 재생하고 같은 자리에 머물러도 반복하지 않는다. 영역 이탈 후 재진입이 필요하고 시작 간격은 최소 5초다. 그림을 통째로 좌우 반전하지 않는다.

[표정 세 가지]
A 기본: 기존 점눈 두 개.
B 짝눈 관찰: 커서 쪽 기본 점눈 sx=1.12, sy=1; 먼 쪽 새 집중 눈. 양 눈의 고정 시선은 시작 방향 x=±8, y=-2 정도.
C 눈웃음: 기존 웃는 눈(index 1) 두 개.
부리는 세 표정 내내 동일. 눈 두 개는 같은 순간에 표정 묶음을 전환한다. 가까운 눈은 세로 확대하지 않아 부리와의 간격을 유지한다.
액션 중 자동 follow·자동 깜빡임은 잠시 막는다. 집중 눈이나 웃는 눈에 자동 추적이 더해지거나 점눈이 뒤에 남지 않게 한다. 긴 크로스페이드로 두 눈이 겹치지 않게 한다.

[타임라인 — 머무름 충족 이후]
0.00~0.25초: A→B. 눈이 먼저 관심을 보이고 몸은 커서 반대쪽으로 1도 살짝 망설였다가 기울기 시작한다.
0.25~0.80초: B 유지. 커서 쪽 body 최대 4도, sx=0.985, sy=1.025 이내. 먼 발은 바깥 x=6px, 위 y=-6px, 바깥 회전 8도 이내로 한 번 꼼지락. 가까운 발은 바닥을 유지한다.
0.80~1.10초: B 유지. 들킨 듯 약 0.15초 멈칫한다. 이때 날개·발을 계속 흔들지 않는다.
1.10~1.65초: C로 양 눈 동시 전환. 몸은 같은 쪽 1.5도로 돌아오고 sx/sy는 1로. wingL +28도, wingR -28도 정도 한 번 으쓱한다.
1.65~2.30초: C 유지. 날개를 천천히 내리며 발끝 한 번만 작게 꼼지락. 반복 파닥임·점프 없음.
2.30~2.80초: A로 양 눈 동시 복귀. 몸이 먼저 바로 서고 날개는 0.1초 늦게 작은 반동 후 정착한다. 현재 커서 위치로 추적을 다시 연결한다.
이후: A. 같은 자리에서 자동 반복하지 않는다.

[발과 날개 — 레이어 유지]
발은 몸통 뒤에 있어 위로만 들면 숨는다. 먼 발이 왼발이면 x=-6,y=-6,rot=-8도, 오른발이면 x=+6,y=-6,rot=+8도 정도로 바깥 방향을 섞는다. 실제 발끝이 보이는 범위로 줄인다.
날개 역시 몸통 뒤 레이어를 유지한다. 올리는 방향은 왼쪽 +, 오른쪽 -다. 28도에서 뿌리 틈이 보이면 각도를 줄이고 얼굴 앞 레이어로 바꾸지 않는다. wingRf는 계속 숨긴다.
몸통과 부리는 별도 모양을 찌그러뜨리지 않고 작은 전체 축척·회전만 사용한다. body 각도는 오른쪽 +4도, 왼쪽 -4도이며 기존 rest에 대한 추가값이다.

[발 접지 보정]
JSON의 ground_contact_hulls_in_part_source_coordinates는 원래 발 PNG 알파로 구한 외곽점이다. 각 foot의 worldMatrices로 변환한 y 최댓값이 현재 바닥 높이다.
기본 rest 자세의 발바닥 최대 y를 baseline으로 유지한다. 현재 root body 구조에서는 body.y += baselineFloorY - currentFloorY로 접지를 보정한다. 실제 로그인에서 부모가 추가되었다면 부모 역변환으로 이동량을 환산한다.
제공한 정적 가이드의 기본 무대 바닥은 y=354.88이다. 이 숫자를 로그인 페이지의 전역 좌표에 하드코딩하지 말고 현재 캐릭터 배치에서 다시 계산한다. 축척·기울임·발 꼼지락과 보정을 중복 누적하지 않는다.

[중도 이탈·우선순위]
커서가 떠나면 어느 단계든 현재 자세에서 0.35~0.5초 동안 A로 복귀한다. 남은 으쓱과 발 동작을 강제로 재생하지 않는다. 창 밖 이탈은 가운데 시선으로 돌아온다. 다시 들어와도 중간 자세가 순간이동하지 않게 한다.
다른 친구와 영역이 겹치면 가장 가까운 한 캐릭터만 새 액션을 시작한다. 이미 다른 친구가 동작 중이면 갑자기 끊지 말고 도로덕은 대기한다.
인트로·입력 중·비밀번호·로그인 전환은 마우스보다 우선한다. 비밀번호 포커스 중에는 추적을 끄고 기존 프라이버시 동작이 있다면 우선한다. 새 타자 모션은 이번에 만들지 않는다.
표시 레이어가 폼 클릭을 가로채지 않게 한다. 모션 감소에서는 몸 기울임·날개·발 동작을 생략하고 작은 눈 추적만 쓴다. 터치 전용 기기에서는 마우스 액션을 자동 실행하지 않는다.

[검수·보고]
1. A/B/C에서 부리는 같은 붉은 타원인지 확인. 입 안 선·벌림·색 변화가 없어야 함.
2. 눈을 아래로 움직일 때 부리와 겹치지 않는지 확인. 가까운 눈 세로 확대와 부리 follow가 켜지지 않아야 함.
3. 좌우 커서에서 먼 눈만 집중 눈이 되는지, C에서는 기존 웃는 눈 두 개로 전환되는지 확인.
4. 0.25배 재생으로 발 접지·먼 발 가림·날개 뿌리·몸 늘이기·연결부 틈 확인.
5. 팻말·글자·wingRf가 숨어 있고 다른 친구나 입력창을 가리지 않는지 확인.
6. 중간 이탈·재진입·빠른 이동·창 밖 이탈·창 크기 변경 확인.
7. 기존 인트로와 팻말·다른 캐릭터를 유지했는지 확인.
