타로타로 한 캐릭터의 로그인 화면 마우스 액션 「한쪽 바퀴로 까딱, 엣헴!」을 구현해줘.
이번에는 타로타로만 작업한다. 기존 다른 다섯 친구와 로그인 인트로를 유지하고, 새 타자 입력 모션은 아직 만들지 않는다.

[전체 장면 맥락]
타로타로는 원래 인트로에서 티라의 불에 놀라고, 점프해 환영 슬로모션 구도를 만든 뒤 한쪽씩 사뿐히 착지하고 엣헴한다. 지금 작업은 이 인트로 이후 모두 작아져 로그인 화면에 남은 상태의 마우스 반응이다. 기존 인트로의 점프·측면 표정·착지를 다시 만드는 작업이 아니다.

[연출]
눈으로 커서를 따라보다가 가까운 쪽 바퀴에 체중을 싣고 반대 바퀴를 살짝 들며 균형을 잡는다. 작은 ㅇ 입으로 집중하다가 기존 엣헴 눈·입으로 뽐내고 반대 바퀴를 사뿐히 내려놓는다. 한쪽 바퀴로 버틴다는 느낌을 살리고 두 바퀴가 함께 떠오르는 점프는 하지 않는다.
그림체는 기존 초록색 차체와 단순한 회색 선 그대로 유지한다. 새 주름·손·팔·느낌표·말풍선·소리는 추가하지 않는다.

[현재 코드 먼저 확인]
tarotaro/tarotaro.json, rig.json, README.md와 실제 로그인·모션 에디터 연결 코드를 읽어줘.
현재 구조는 rig→land→body이며 눈·입·차체·귀·번개 안테나·바퀴는 body 자식이다. bodyImg 0은 정면, 1은 15도 측면. eyes와 mouth는 0=빵긋, 1=15도 놀람, 2=엣헴이다.
기존 기본 눈은 감은 웃음 눈이고 follow도 꺼져 있다. tt_idle의 follow='center'를 포함해 기존 기본 상태가 그대로면 새 눈을 넣어도 추적이 막힌다. 로그인 전용 마우스 대기 상태를 만들어 그때만 따라보게 한다. 기존 tt_idle, fA/fB/fC, 인트로 데이터는 전역으로 덮어쓰지 않는다.
현재 stage=400×400, rig pivot=(600,1155), rest=(200,385), scale=0.3. 원본 가이드 400×420을 3배한 단위로 좌표가 저장되어 있다. 새 PNG의 1254 캔버스가 이 엔진 좌표계 크기라는 뜻은 아니다.

[추가 PNG 두 장]
01 눈_점눈공용: 단순한 회색 점눈 하나. 좌우에 두 번 사용.
02 입_정면호기심: 정면용 작은 회색 ㅇ 입.
모두 1254×1254 투명 배경이고 내장 이미지 생성 출력 원본 그대로다. source_rect→guide_draw_rect 또는 full_png_variant_rect를 이용해 배치한다. PNG 전체를 같은 좌표에 단순 오버레이하지 않는다.
점눈 중심은 왼쪽 (539,681), 오른쪽 (661,681), 기본 크기 54×54. 새 입 중심은 기존 정면 빵긋 입과 같은 (600,795), 크기 60×78 정도. 부모는 body다.
현재 eyes 파츠는 두 눈이 한 이미지에 들어 있다. 기존 eyes를 계속 두고 새 점눈 두 표시를 별도로 추가하되, A/B에서는 기존 eyes를 숨기고 C에서는 새 점눈 둘을 숨긴다. 단일 PNG를 두 번 쓰는 방식이다.
기존 놀람 입 index 1은 측면용으로 x/y가 왼쪽·아래에 치우쳐 있으므로 정면용 ㅇ 입으로 재사용하지 않는다.

[마우스 표정 세 개]
마우스 A: bodyImg 0, 새 점눈 두 개 ON, 기존 eyes OFF, 기존 mouth 0 ON, 새 입 OFF.
B 집중: bodyImg 0, 새 점눈 두 개 ON(약 1.06배), 기존 eyes OFF, 기존 mouth OFF, 새 호기심 입 ON.
C 엣헴: bodyImg 0, 기존 eyes 2 ON, 새 점눈 둘 OFF, 기존 mouth 2 ON, 새 호기심 입 OFF.
excl은 대기·액션 내내 OFF다. 눈·입과 표시 상태를 같은 순간에 묶어 바꾼다. 기존 인트로의 ‘A 기본·환영(눈 감음)’과 구별해 mouse_A/B/C 같은 별도 이름을 쓴다.
마우스 반응 동안 bodyImg는 항상 정면 0. 측면 몸통·귀·눈·입 조합이 섞이지 않게 한다. 기존 정면의 초록색 차체·표시 무늬·검은 선을 그대로 유지한다.

[기본 따라보기]
새 점눈 두 개는 같은 방향으로 원본 좌표 좌우 최대 8px, 상하 최대 6px 움직인다. 기본 0.3배 무대에서 좌우 약 2.4px이며 실제 표시 배율에 비례한다.
입은 고정. 몸은 눈보다 약 0.1초 늦게 최대 1도만 반응하고 바퀴는 바닥을 유지한다. 눈을 따라보기 위한 새 파츠와 기존 paired eyes에 동시에 follow를 켜지 않는다.
실제 표시 경계로 커서를 정규화하고 시간 기반 보간을 사용한다. 기존 rAF에 통합하며 mousemove마다 새 루프·타이머를 쌓지 않는다.

[시작과 재시작]
표시 경계 및 주변 약 0.25H에서 커서가 0.85초 머무르면 시작. H는 표시 높이. 약 14 CSS px 넘게 이동하면 머무름 시간을 다시 센다.
시작 시 방향을 고정. 왼쪽이면 왼바퀴 지지, 오른쪽이면 오른바퀴 지지. 가운데 작은 구간에서는 직전 방향을 유지하고 처음부터 가운데면 왼쪽.
약 2.7초 한 번 재생 후 같은 자리에서 반복하지 않는다. 영역 이탈·재진입이 필요하고 시작 간격 최소 6초. 다른 친구와 영역이 겹치면 가장 가까운 한 명만 시작하며, 이미 다른 친구가 움직이고 있으면 끊지 않고 대기한다.

[타임라인 — 머무름 충족 이후]
0.00~0.25초: B로 눈·입 동시 전환. 가까운 바퀴에 무게를 싣고 2도 기울이기 시작. 점눈은 시작 방향 x=±8,y=-4 정도로 고정.
0.25~0.85초: B 유지. 지지 바퀴를 축으로 최대 6도까지 까딱. 반대 바퀴만 약간 듦. 귀와 번개 안테나가 0.1초 늦게 작은 반동.
0.85~1.15초: B 유지. 약 0.15초 균형 자세를 멈춰 보여준다. 계속 흔들리는 루프는 쓰지 않는다.
1.15~1.60초: C로 눈·입 동시 전환. 6도→3도로 천천히 돌아오며 엣헴. 귀는 살짝 올라가고 안테나는 늦게 정착.
1.60~2.15초: C 유지. 3도→0도, 반대 바퀴를 사뿐히 내려놓음. 양 바퀴가 닿은 뒤에만 1% 이내 눌림 한 번 후 복원. 점프나 반동 이륙 없음.
2.15~2.70초: 마우스 A로 눈·입 동시 복귀. 귀·안테나가 0.1초 늦게 정착하고 현재 커서 추적으로 연결.
이후: 마우스 A. 같은 자리에서 다시 시작하지 않음.
액션 중 자동 follow와 자동 깜빡임은 잠시 막는다. 엣헴 눈이 자동 시선 이동에 밀려나지 않게 한다. 한 바퀴 균형 중 body.sx/sy=1을 유지해 숨쉬기와 중복 변형하지 않는다.

[한쪽 바퀴 회전축 — 필수]
기존 land는 인트로용 왼바퀴 축이므로 전역 피벗을 바꾸지 않는다. 이번 마우스 동작에서 land.rot=0, body로 균형 동작을 만든다.
body pivot P=(600,1155). 선택한 바퀴 바닥 기준 A는 왼쪽 (408,1155), 오른쪽 (792,1155).
왼바퀴 지지는 theta=-6도, 오른바퀴 지지는 theta=+6도.
body.rot=theta와 동시에 body의 원래 위치에 아래 이동을 더한다:
T = A + R(theta)*(P-A) - P
왼쪽 6도 초기 T는 약(-1.052,-20.069), 오른쪽은 약(+1.052,-20.069)이며 원본 좌표 단위다. 화면 픽셀로 직접 쓰지 않는다. 단계별 각도에 맞춰 T도 매 프레임 함께 계산한다.
몸 중심만 돌리면 지지 바퀴도 움직여 균형이 깨진다. 바퀴를 개별로 떼어 올려 공중에 붙이는 방식도 쓰지 않는다. 차체와 반대 바퀴가 선택한 바퀴를 축으로 함께 움직여야 한다.

[접지 보정]
JSON의 wheel_ground_hulls_in_part_source_coordinates는 원래 바퀴 PNG 알파로 구한 외곽점이다. 현재 각 wheel의 worldMatrices로 변환해 y 최댓값을 계산한다.
기본 자세 바닥 높이와 현재 최대 y의 차이를 부모 land의 역변환으로 환산한 이동량만큼 body에 더한다. 기본 rig 배율 0.3에서는 세로 차이/0.3이 부모 좌표 이동량이지만 실제 로그인에서는 현재 행렬로 환산한다. rig 전체를 움직이지 않는다.
정적 가이드에서는 기본 바닥 y=384.7을 유지하며 반대 바퀴가 약 12px 들린다. 이 숫자를 로그인 페이지 전역 좌표로 하드코딩하지 않는다. 실제 캐릭터 배치에서 기준 바닥을 다시 계산한다.
중도 취소에서도 회전과 T, 접지 보정을 함께 풀어 양 바퀴가 부드럽게 내려오게 한다.

[귀·안테나]
기울임 중 귀는 원본 대비 좌우 6도 안팎, 번개 안테나는 몸 기울임 반대쪽으로 최대 4도 정도의 지연 반동을 준다. 엣헴에서는 귀 4도 정도, 안테나 2도 정도로 줄인다.
차체 연결부 뒤 레이어와 현재 피벗을 유지한다. 틈이 보이면 각도를 줄인다. 한쪽 바퀴 동작이 주인공이므로 귀를 계속 파닥이지 않는다.

[취소·우선순위]
커서가 떠나면 현재 자세에서 0.4~0.55초 동안 양 바퀴를 내려놓고 마우스 A로 복귀한다. 남은 엣헴·착지를 강제로 끝까지 재생하지 않는다. 창 밖 이탈은 가운데 시선으로 돌아온다.
인트로·입력 중·비밀번호·로그인 전환은 마우스보다 우선한다. 비밀번호 포커스 중에는 추적을 끄고 기존 프라이버시 동작이 있다면 우선한다. 이번에는 새 타자·비밀번호 동작을 만들지 않는다.
폼 클릭을 표시 레이어가 가로채지 않게 한다. 모션 감소에서는 한쪽 바퀴·귀·안테나 모션을 생략하고 작은 점눈 추적만 쓴다. 터치 전용 기기에서는 마우스 액션을 자동 실행하지 않는다.

[검수·보고]
1. A/B/C 모두 정면 bodyImg 0, 초록색 차체·표시·선이 유지되는지 확인.
2. 새 점눈 두 곳과 새 입이 원래 정면 얼굴의 중심·간격에 맞는지 확인. 기존 측면 놀람 표정이 섞이지 않아야 함.
3. 표정별 기존 양눈/새 점눈/기존 입/새 입 표시 상태가 함께 바뀌고 두 겹이 되지 않아야 함.
4. 좌·우 균형을 0.25배 속도로 확인. 지지 바퀴 접지, 반대 바퀴만 들림, 반대 바퀴의 사뿐한 복귀가 보여야 함.
5. 최대 각도에서 귀·안테나 뿌리 틈과 프레임 잘림 확인.
6. 중도 이탈·재진입·빠른 이동·창 밖 이탈·창 크기 변경에서 회전과 이동 보정이 따로 끊기지 않는지 확인.
7. 기존 인트로의 15도 놀람·점프·착지·엣헴과 다른 친구들이 유지되는지 확인.
수정 파일, 수동 재생 방법, 실제 확인한 항목과 남은 검수 항목을 알려줘.

우선 타로타로 이 범위까지만 완성해줘. 여섯 캐릭터의 통합 배치와 다음 타자 액션은 별도 단계다.
