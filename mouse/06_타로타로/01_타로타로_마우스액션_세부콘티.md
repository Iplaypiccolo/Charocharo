# 타로타로 마우스 액션 — 「한쪽 바퀴로 까딱, 엣헴!」

타로타로 하나의 로그인 화면 마우스 액션이다. 기존 인트로의 불꽃 보고 놀라기·점프·환영·한쪽씩 착지하기는 유지한다. 이번 동작은 모두 작아져 로그인 화면에 자리 잡은 뒤 사용한다.

## 연출 방향

타로타로가 눈으로 커서를 바라보다 한쪽 바퀴로 잠깐 균형을 잡는다. 작은 ‘ㅇ’ 입으로 집중한 뒤, ‘이 정도야!’ 하듯 기존 엣헴 표정을 짓고 반대 바퀴를 사뿐히 내려놓는다. 티라의 덤벙거림이나 도로덕의 빼꼼과 달리, **작은 균형 묘기와 뿌듯함**이 핵심이다.

표정은 마우스용 A 기본(눈뜸), B 집중, C 엣헴 세 가지다. 귀·번개 안테나는 몸이 움직인 뒤 조금 늦게 따라온다. 큰 점프·공중제비·장거리 이동은 하지 않는다. 새 느낌표나 말풍선도 넣지 않는다.

## 현재 파츠에서 필요한 변화

현재 기본 눈은 감은 웃음 눈이고, 눈·입의 자동 follow도 꺼져 있다. 따라보기용 점눈 한 장을 새로 만들고 좌우 두 번 사용한다. 기존 눈 파츠는 양 눈이 한 PNG에 들어 있으므로, 새 점눈은 왼쪽·오른쪽 표시를 별도로 제어한다.

정면 집중 표정에 맞는 작은 ‘ㅇ’ 입도 새로 만든다. 기존 놀람 입(index 1)은 15도 측면 몸통용이라 정면에서는 위치가 왼쪽·아래로 치우친다. 정면 입으로 그대로 사용하지 않는다.

마우스 액션 내내 bodyImg는 기존 정면(index 0)을 유지한다. 15도 몸통(index 1)이나 옆모습의 색·선을 바꾸지 않는다. 기존 엣헴 눈·입(index 2)은 그대로 재사용한다.

## 기본 따라보기

- 기존 정면 몸통과 빵긋 입(index 0)에 새 점눈 두 개를 조립한다. 이것이 **마우스용 A**이며 기존 인트로의 눈 감은 A 프리셋을 덮어쓰지 않는다.
- 점눈 중심은 기존 웃는 눈의 각 그림 영역 중심인 왼쪽 (539,681), 오른쪽 (661,681). 크기는 54×54 정도로 시작한다.
- 두 점눈은 같은 방향으로 원본 좌표 좌우 최대 8px, 상하 최대 6px만 움직인다. 기본 0.3배 무대에서는 좌우 약 2.4px다.
- 입은 고정한다. 몸은 눈보다 약 0.1초 늦게 좌우 1도 이내로만 반응하고 바퀴는 바닥을 유지한다.
- 기존 tt_idle에는 follow='center'가 있으므로 로그인 마우스 상태에서 별도 따라보기 상태를 사용한다. tt_idle과 기존 인트로를 전역 수정하지 않는다.

## 시작 조건

타로타로의 표시 경계 및 주변 약 0.25H 안에서 커서가 0.85초 머무르면 시작한다. H는 화면에 표시된 캐릭터 높이이며 약 14 CSS px 넘게 이동하면 머무름 시간을 다시 센다.

시작 순간 방향을 고정한다. 왼쪽이면 왼바퀴로 버티고 오른바퀴를 살짝 들며, 오른쪽이면 반대다. 가운데 작은 구간에서는 직전 방향을 유지하고 처음부터 가운데면 왼쪽을 선택한다. 그림을 통째로 반전하지 않는다.

약 2.7초 한 번 재생하고 같은 자리에 머물러도 반복하지 않는다. 재생 후 영역 이탈·재진입이 필요하며 시작 간격은 최소 6초다. 다른 친구와 영역이 겹치면 가장 가까운 한 명만 시작한다.

## 세부 콘티

시간은 머무름 조건 충족 후 액션 시작부터 센다.

| 시간 | 장면 | 표정 | 몸·바퀴·귀 |
|---|---|---|---|
| 대기 | 커서 따라보기 | 마우스용 A: 새 점눈 + 기존 빵긋 입 | 양 바퀴 바닥. 몸은 제자리 |
| 0.00–0.25초 | ‘한번 볼까?’ | B: 점눈 약 1.06배, 작은 ‘ㅇ’ 입 | 커서 쪽 바퀴에 무게를 싣고 2도 정도 기울이기 시작 |
| 0.25–0.85초 | 한쪽 바퀴로 까딱 | B 유지 | 지지 바퀴를 축으로 최대 6도. 반대 바퀴만 살짝 듦. 귀와 번개 안테나는 0.1초 늦게 작은 반동 |
| 0.85–1.15초 | 균형 성공, 잠깐 정지 | B 유지 | 0.15초 정도 균형 자세를 유지. 계속 좌우로 반복 흔들지 않음 |
| 1.15–1.60초 | ‘이 정도야, 엣헴!’ | C: 기존 엣헴 눈·입으로 동시 교체 | 같은 바퀴에 버틴 채 6도→3도로 천천히 돌아옴. 귀가 살짝 올라가고 안테나가 늦게 정착 |
| 1.60–2.15초 | 반대 바퀴를 사뿐히 내려놓음 | C 유지 | 3도→0도. 양 바퀴가 닿은 뒤 1% 이내로 한 번만 눌렸다 복원. 점프·튀어 오름 없음 |
| 2.15–2.70초 | 친근한 기본으로 | 마우스용 A로 눈·입 동시 복귀 | 귀·안테나가 0.1초 늦게 작은 반동 후 정착. 현재 커서 추적으로 연결 |
| 이후 | 커서만 따라보기 | 마우스용 A | 재진입 전까지 반복하지 않음 |

한쪽 바퀴를 든 동안 body의 sx/sy는 1로 두어 기존 호흡이 균형 축에 겹치지 않게 한다. 1% 착지 눌림은 양 바퀴가 내려온 뒤에만 사용한다.

## 표정 조립과 표시 상태

| 표정 | 몸통 | 기존 양눈 파츠 | 새 점눈 | 입 |
|---|---|---|---|---|
| 마우스 A | bodyImg 0 | 숨김 | 좌우 모두 켬 | 기존 mouth 0 |
| B 집중 | bodyImg 0 | 숨김 | 좌우 모두 켬, 1.06배 | 기존 mouth 숨김, 새 호기심 입 |
| C 엣헴 | bodyImg 0 | eyes 2 켬 | 좌우 모두 숨김 | 기존 mouth 2 |

새 호기심 입은 A/C에서 숨기고, 느낌표 excl은 이번 대기·액션 내내 숨긴다. 눈·입과 표시 상태를 같은 순간에 바꿔 두 겹이 되지 않게 한다. 자동 깜빡임과 자동 추적은 액션 중 잠시 중단하고 시작 방향의 시선만 유지한다.

## 한쪽 바퀴 축과 접지

현재 구조는 rig → land → body다. land는 기존 인트로에서 왼바퀴 착지 회전을 담당하므로 이번 작업에서 피벗을 전역 변경하지 않는다. 마우스 동작 중에는 land.rot=0을 유지한다.

body 피벗 P=(600,1155), 왼바퀴 아래 기준 A_L=(408,1155), 오른바퀴 아래 A_R=(792,1155)다. 왼쪽으로 균형 잡기는 θ=-6도, 오른쪽은 θ=+6도다.

body를 자기 중심으로만 돌리면 지지 바퀴까지 움직인다. 다음 이동을 body의 기본 위치에 더해 선택한 바퀴를 축으로 회전시킨다.

`이동량 = A + R(θ)·(P−A) − P`

기본 크기에서 왼쪽 6도는 대략 x=-1.052, y=-20.069, 오른쪽은 x=+1.052, y=-20.069의 원본 좌표 이동이다. 값은 원본 좌표이며 기본 무대에서는 rig 배율 0.3을 함께 받는다. 페이지 전역 픽셀로 그대로 적용하지 않는다.

JSON의 바퀴 알파 외곽점을 worldMatrices로 변환해 지지 바퀴 바닥과 기준 바닥 높이를 확인한다. 추가 접지 보정은 부모 land의 역변환으로 환산한 이동량을 body에 적용한다. rig 전체를 올려 다른 친구와의 배치를 바꾸거나 바퀴를 원래 연결부에서 떼어 움직이지 않는다.

반대 바퀴의 최대 들림은 기본 무대에서 대략 12px 정도다. 실제 로그인의 작은 크기에서는 더 작게 보인다. 한쪽 바퀴가 버티고 있다는 느낌이 먼저 읽혀야 하며, 두 바퀴가 함께 떠 보이면 각도와 이동을 줄인다.

## 이미지 배치

새 PNG는 각각 1254×1254 투명 캔버스의 독립 파츠다. 기존 엔진 좌표는 원래 400×420 가이드의 3배 단위이므로, 새 PNG 크기를 기존 좌표계 크기로 착각하지 않는다. 실제 위치는 JSON의 source_rect→guide_draw_rect 또는 full_png_variant_rect로 넣는다.

점눈은 좌우 중심 (539,681)/(661,681)에 54×54. 새 입은 기존 정면 빵긋 입 중심 (600,795)에 60×78 정도로 조립한다. 부모는 모두 body다. 기존 엣헴 입은 원래 위치(index 2)를 유지한다.

## 중도 이탈

커서가 떠나면 어느 단계든 현재 각도에서 0.4–0.55초 동안 양 바퀴를 바닥에 내려놓고 마우스 A로 복귀한다. 반대 바퀴가 든 상태에서 회전만 먼저 0으로 초기화해 순간이동시키지 않는다. 회전과 축 보정 이동을 함께 풀어야 한다.

창 밖 이탈도 가운데 시선으로 돌아온다. 남은 엣헴이나 착지 박자를 강제로 끝까지 재생하지 않는다. 재진입 시 타이머·루프가 중첩되지 않게 한다.

## 검수

1. 마우스 A/B/C는 모두 정면 bodyImg 0인지 확인한다. 15도 놀람 몸통·눈·입이 섞이지 않아야 한다.
2. 새 점눈 두 개가 원래 웃는 눈 자리와 간격을 유지하고, 새 입은 정면 입 중심에 있어야 한다.
3. A/B/C 전환 때 기존 양눈·새 점눈·기존 입·새 입이 올바르게 함께 켜지고 꺼져야 한다.
4. 좌우 균형 동작을 각각 느리게 재생해 지지 바퀴가 바닥에 남는지, 반대 바퀴만 드는지 확인한다. 몸 중심 회전만 적용하지 않는다.
5. 귀·안테나 연결부 틈과 프레임 잘림을 확인한다. 기존 land 피벗과 인트로 착지·옆모습을 변경하지 않는다.
6. 빠른 이동·중도 이탈·재진입·창 밖 이탈·화면 크기 변경을 확인한다. 회전과 이동 보정이 따로 끊기지 않아야 한다.
7. 인트로·입력·비밀번호·로그인 전환이 마우스보다 우선한다. 이미 동작 중인 다른 친구를 갑자기 끊지 않는다. 이번에는 타자 동작을 만들지 않는다.
8. 모션 감소에서는 한쪽 바퀴 균형·귀·안테나 동작을 생략하고 작은 점눈 추적만 쓴다. 터치 전용 기기에서는 자동 마우스 액션을 실행하지 않는다. 표시 레이어가 폼 클릭을 가로채지 않게 한다.
