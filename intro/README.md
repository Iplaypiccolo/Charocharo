## 로그인 사이트에 붙일 때 (아직 붙이지 않음)
- `charo-pet.js`를 **data-src 없이** 넣고(자동으로 펫이 붙지 않음), `charo-intro.js`·`welcome-fx.js`·배치표·`assets/`를 넣음. `charo-fly.js`는 같이 넣지 않음(재생기가 감지하면 콘솔 경고).
- 시작: `CharoIntro.create({...}).start()` / 건너뛰기: `.skip()`(정상 종료와 같은 자리·자세) / 모션 줄이기: `reduce: true`.
- 그림을 다 불러온 뒤에만 시작하고, 하나라도 못 열면 시작하지 않음(`info().state === 'error'`).
- 사이트 CSP 때문에 파일을 저장소 안에 복사해 쓰는 방식이 맞음(HTML 안 스크립트 금지 → 시작 코드는 별도 js 파일).
- 효과 그림 중 배경·입자를 못 불러오면 그것만 빼고 진행, 문구 그림을 못 불러오면 시작하지 않음. 캔버스는 `pointer-events:none`, '환영합니다!'는 `onWelcome`으로 화면 낭독용 글자 한 번만.
