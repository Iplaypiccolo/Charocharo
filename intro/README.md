# 로그인 인트로 (차로차로 동작 + 공통 시간축 재생기)

| 파일 | 내용 |
|---|---|
| `charo-intro.js` | 인트로 재생기. 여러 캐릭터를 **하나의 시간축**으로 그림(requestAnimationFrame 하나, setTimeout 연결 없음). 바깥 층 = 위치·표시 크기(다가오기·대형·정렬 축소), 캐릭터 동작 = 몸통 점프·기울기·날개·표정 |
| `intro-cast.js` | 배치표: 캐릭터별 동작 구간·위치 키·정렬 자리 (검수용 값) |
| `index.html`, `preview.js` | 검수 페이지. 큰 ‘환영합니다!’와 둥근 배경은 **위치 확인용 임시 표시** |
| `tools/build_charo_intro.py` | `charo-pet.json`에 `i_charo`(6.7초), `i_charo_r`(모션 줄이기), 표정 `f22`를 넣는 스크립트(기존 파츠·동작·표정은 그대로) |
| `tests/` | `check_charo.js`(동작 데이터 검사), `t_intro.py`(크롬 재생 검사)와 결과 |
| `검수/` | 미리보기 GIF·프레임 |

## 차로차로 표정
- A = 기존 `f00` (눈·눈썹·입 모두 0번)
- B = 새 `f22 신나서 질끈 (인트로)` = 눈 3번 `질끈 > <`, 눈썹 3번 `질끈 > < 눈썹`, 입 1번 `폭소 (이·혀)`. 스크립트가 이름으로 번호를 다시 확인함. `f09`·`f21`은 그대로
- 순서 A(0초) → B(2.30초, 땅에서 떨어지는 순간) → A(4.55초, 착지 정리 뒤). 다섯 그림을 같은 순간에 바꿈

## 시간표 (차로차로)
| 초 | 내용 |
|---|---|
| 0.00–1.20 | 멀리서 작게 → 오른쪽 아래 자리(바깥 층). 몸통 4번 통통(H의 7.5→2%), 좌우 4.5→3° 기울기, 날개는 0.05초 늦게. 1.16 몸이 멈춘 뒤 날개가 한 번 더(1.27) |
| 1.20–2.25 | 1.22 짧게 눌림(0.93) → 복귀. 티라 구간엔 작은 들썩임 2번(최대 3px). 2.02–2.16 날개 살짝 들고 멈춤 |
| 2.25–2.55 | 2.28 웅크림(0.90) → 2.30 이륙(B 표정) · 0.06초 간격 파닥 · 오른쪽 날개 0.025초 늦게 |
| 2.55–4.15 | 슬로모션: 3.30 정점(H의 17% = 39.7px). 몸 약 5° 기울기, 날갯짓 1.5번(왼쪽 기준), 오른쪽은 0.12초 늦고 조금 덜 |
| 4.15–4.55 | 4.36 착지 눌림(0.92) · 날개는 위에 남았다 4.47에 내려옴 · 작은 반동 1번 · 4.55 A |
| 4.55–5.35 | 날개 끝 한 번 정리(6°) · 첨다니 공중제비 방해 없음 |
| 5.35–6.70 | 바깥 층이 함께 작아지며(×0.55) 아래 줄 네 번째 자리로. 몸통 동작은 끝 자세 = 기본 자세 → 대기 숨쉬기(`c_breath`)로 끊김 없이 |

## 로그인 사이트에 붙일 때 (아직 붙이지 않음)
- `charo-pet.js`를 **data-src 없이** 넣고(자동으로 펫이 붙지 않음), `charo-intro.js`와 배치표를 넣음. `charo-fly.js`는 같이 넣지 않음(재생기가 감지하면 콘솔 경고).
- 시작: `CharoIntro.create({...}).start()` / 건너뛰기: `.skip()`(정상 종료와 같은 자리·자세) / 모션 줄이기: `reduce: true`.
- 그림을 다 불러온 뒤에만 시작하고, 하나라도 못 열면 시작하지 않음(`info().state === 'error'`).
- 사이트 CSP 때문에 파일을 저장소 안에 복사해 쓰는 방식이 맞음(HTML 안 스크립트 금지 → 시작 코드는 별도 js 파일).
