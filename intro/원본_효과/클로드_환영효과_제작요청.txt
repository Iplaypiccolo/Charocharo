로그인 인트로의 환영 장면에 첨부한 문구·폭죽·색종이 파츠를 적용해줘.

1. 작업 범위와 기준
친구들의 정면 달리기 → 환영 대형에서 슬로모션 → 첨다니 왼쪽 공중제비 → 최종 정렬·축소 → 로그인 화면이라는 기존 콘티를 유지한다.
이번에는 환영 효과만 추가한다. 캐릭터 파츠와 표정, 티라의 무팔 설정·입으로 문 거꾸로 환영 팻말은 변경하지 않는다. 새 겨울 배경이나 캐릭터를 그리지 않는다.
기존 겨울 배경, 큰 환영 문구, 폭죽과 색종이는 환영 슬로모션 구간에만 나타난다. 달려오는 구간과 최종 로그인 대기 화면에는 남기지 않는다.
대상 사이트의 실제 타임라인과 레이어 구조를 먼저 확인하고 반영해줘.

2. 파일 사용법
01_환영합니다_문구.png: 상단의 큰 문구 전체다. 글자를 다시 입력해 겹치거나 캐릭터 팻말에 붙이지 않는다.
02_폭죽_완성형.png: 폭죽 조립 모양 참고 및 간단한 대체 재생용이다.
03~05: 개별 폭죽 불꽃 한 조각, 노랑·분홍·하늘색이다. 권장하는 실제 재생 방식은 이 조각들을 복제해 원형으로 퍼뜨리는 것이다.
06~08: 개별 색종이 한 조각, 노랑·분홍·하늘색이다. 복제하고 회전시켜 사용한다.
완성형 폭죽과 개별 불꽃으로 만든 폭죽을 같은 위치에 중복 표시하지 않는다.

이미지마다 캔버스와 투명 여백이 다르다. 효과_배치정보.json의 실측 source rectangle과 anchor를 참고하고, 보이는 그림의 길이·폭을 기준으로 배치해줘. 전체 PNG 가로폭만으로 크기를 맞추면 조각별 크기가 달라진다.
픽셀 좌표는 PNG 원본 기준이며 배치 가이드는 환영 무대 안의 정규화 좌표다. 전체 브라우저 창 좌표와 혼용하지 않는다. 제공 배치는 시작점이고, 최종 판단은 실제 캐릭터·글자와의 겹침 검수로 한다.

3. 문구 연출
첨부 시안처럼 무대 상단 중앙에 배치한다. 보이는 문구 폭은 무대 폭의 약 56%부터 조정한다.
슬로모션 시작에 약 0.3초 동안 왼쪽에서 오른쪽으로 살짝 펼쳐 보이게 reveal하고, 전체 scale 0.88 → 1.04 → 1.0으로 한 번만 부풀었다 안착한다.
문구 전체를 계속 흔들거나 각 글자를 분해하지 않는다. 기존 환영합니다! 문구 PNG는 한 장이다. 글자별 모핑용 데이터가 있다고 가정하지 않는다.
흰색 스티커 테두리는 PNG에 포함돼 있으므로 별도 굵은 테두리나 빛 번짐을 추가하지 않는다.

4. 폭죽 연출
첨부 시안처럼 문구의 왼쪽 아래와 오른쪽 아래, 친구들 뒤에 한 번씩 터뜨린다. 시작점은 무대 정규화 좌표 (0.17,0.36), (0.84,0.35)다.
폭죽 하나의 최종 지름은 무대 폭의 약 10~13% 정도로 작게 유지한다.
03~05 조각을 하나당 10~12개, 세 색이 고르게 섞이도록 배치한다. 원본 조각의 뾰족한 끝은 아래를 향하고 둥근 끝은 위를 향한다. 각 조각의 source anchor를 회전 기준으로 사용해, 뾰족한 끝이 폭죽 중심을 향하게 한다.
작은 반경에서 바깥쪽으로 빠르게 퍼졌다 감속하고, 마지막에는 약간 처지며 사라지게 한다. 반경·조각 길이·지연을 조금씩 달리해 기계적인 원처럼 보이지 않게 한다. 전체를 빙글빙글 돌리지는 않는다.
오른쪽 폭죽은 왼쪽보다 약 0.10~0.15초 늦게 시작해 한 번만 교차 강조한다.
권장 로컬 타이밍: 슬로모션 시작 후 0.08초 왼쪽 시작, 0.20초 오른쪽 시작, 0.35~0.65초 바깥으로 펼쳐짐, 이후 천천히 벌어지며 끝 0.25초 동안 페이드아웃.
이 초는 약 1.6초 환영 구간을 기준으로 한 제안이다. 실제 구간 길이에 비례해 조정한다.

5. 색종이 연출
여러 각도 이미지를 별도로 만들 필요가 없다. 단색 종이이므로 한 조각을 복제해 중심을 기준으로 rotateZ와 rotateX/rotateY를 조합하면 된다.
CSS 3D를 쓴다면 뒷면도 같은 색으로 보여야 하므로 backface-visibility: visible을 사용한다. Canvas라면 종이 회전에 맞춰 가로폭을 cos 함수로 줄였다 늘리고, 앞뒤 색을 동일하게 유지한다. 별도의 접힌 종이 이미지가 있다고 가정하지 않는다.
데스크톱은 총 18개 안팎, 모바일은 10개 안팎부터 시작한다. 무대 양옆과 문구 주변의 여백에 분산한다. 화면 전체를 덮는 색종이 사진이나 전면 오버레이로 사용하지 않는다.
보이는 종이의 긴 변은 무대 폭의 약 1.0~1.8%로 맞추고, 색·초기 회전·뒤집히는 속도·위상을 서로 다르게 한다.
처음에는 위·바깥으로 살짝 솟았다가 중력으로 느리게 내려오며 좌우로 흔들리게 한다. 모든 종이가 동시에 같은 방향으로 돌지 않게 한다.
캐릭터 얼굴·팻말 글자·큰 환영 문구와 로그인 입력칸에는 금지 영역을 둔다. 실제 요소의 bounding box에 작은 여유를 더해 입자 경로를 사전에 배치하거나, 대부분을 캐릭터 뒤쪽 레이어에 둔다. 매 프레임 충돌 계산을 복잡하게 늘릴 필요는 없다.

6. 시간과 레이어
모든 효과는 기존 인트로의 공통 타임라인을 따른다. 환영 구간 로컬 진행도를 사용해 문구·폭죽·색종이를 샘플링한다.
전체 콘티에 이미 슬로모션 시간 변환이 있다면 효과에도 한 번만 적용한다. 효과에 별도 슬로모션을 또 곱하지 않는다.
일반 속도에서 자연스러운 전체 동작을 먼저 맞추고 환영 슬로모션에 연결한다. 캐릭터만 느려지고 폭죽·색종이는 정상 속도로 끝나는 현상을 피한다.
권장 레이어: 기존 겨울 배경 → 폭죽/대부분의 색종이 → 친구들 → 상단 환영 문구. 앞쪽 색종이는 비어 있는 여백에만 소수 허용한다.
슬로모션 종료 전 마지막 0.2~0.25초 동안 배경과 효과를 정리하고, 첨다니 공중제비를 시작할 때는 남은 입자가 얼굴이나 이동 경로를 가리지 않게 한다. 캐릭터가 작아질 때 효과까지 로그인 화면 아래로 따라가게 하지 않는다.

7. 구현과 검수
파츠는 먼저 preload하고 기존 requestAnimationFrame/타임라인에 통합한다. 입자별 setInterval이나 매 프레임 Math.random으로 모양이 튀는 구현은 피한다. seed와 입자 속성은 시작 시 한 번 정한다.
장식 레이어는 pointer-events: none으로 입력을 방해하지 않게 하고, 환영 의미는 접근 가능한 DOM 텍스트로 한 번만 전달한다. 장식 입자 이미지는 중복 낭독하지 않게 한다.
건너뛰기·재시작·리사이즈·페이지 비활성화 후 복귀에서 잔여 입자나 중복 타이머가 남지 않게 한다.
동작 줄이기 설정에서는 정적인 환영 문구와 소수 장식만 짧게 보여주거나 기존 간소화 흐름을 따른다.
검수는 달려오기 전후 → 환영 문구 펼침 → 양쪽 폭죽 → 색종이 회전·낙하 → 슬로모션 종료 → 첨다니 공중제비 → 로그인 화면까지 한다. 세 효과가 환영 구간 밖에 남지 않는지, 문구 철자·흰 테두리·모바일 잘림·캐릭터 얼굴 가림을 확인해줘.
완료 후 실제 수정 파일과 재생 검수 결과를 알려줘. 제공된 배치와 타이밍은 제안값이며 대상 사이트에서 이미 검수된 값은 아니다.
