# 타로타로 (로그인 인트로 여섯 번째 친구) — 모션 1차

받은 ZIP(`원본/`)의 PNG 14장을 `조립_시작값.json`의 잘라낼 영역(source_rect)과 가이드 자리(guide_draw_rect)대로 조립했습니다. 엔진 좌표 = 가이드(400×420) × 3.

| 위치 | 내용 |
|---|---|
| `tarotaro.json` / `rig.json` | 캐릭터 파일 / 기준점·잘라낸 영역·표정 조합·시간표 |
| `검수본/` | 잘라 낸 그림(엔진 좌표의 절반 해상도로 저장) |
| `tarotaro_preview.gif`, `tarotaro_landing_slow.gif`, `motion_frames.png` | 미리보기 |
| `도구/build.py` | 다시 만드는 스크립트 |

## 구조(뒤 → 앞)
`rig`(무대 위치·크기) → `land`(한쪽 착지 회전, 축 = 왼쪽 바퀴 바닥) → `body`(눌림·기울기, 축 = 바퀴 끝 가운데) → 안테나 · 귀 좌우 · 바퀴 좌우 → 몸통(정면/왼쪽15도) → 눈 → 입 → 느낌표.

## 표정(정확히 세 종류, 몸통·눈·입을 같은 순간에)
- A 기본·환영: 몸통01 + 눈08 + 입09
- B 놀람: 몸통02(왼쪽 15도) + 눈10 + 입11, 이때 귀·안테나 위치 보정(가이드 값), 느낌표는 0.37~0.90초만
- C 엣헴: 몸통01 + 눈12 + 입13
순서 A(0) → B(0.37) → A(1.74, 이륙) → C(4.45) → A(4.85)
