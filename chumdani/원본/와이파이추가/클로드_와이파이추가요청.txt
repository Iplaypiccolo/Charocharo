클로드 전달용 — 첨다니 와이파이 감정 연출 추가

기존 첨다니 조립·모션 작업에 아래 기능을 추가해 주세요. 전체 콘티와 최종 배치는 유지합니다. 기존 지시의 ‘아래쪽 파란 무늬는 고정’ 항목만 변경합니다. 전조등은 계속 고정하며, 와이파이는 입이 아닌 독립된 감정 표시 파츠입니다.

1. 추가 파일
- 첨다니_차체바탕_와이파이분리.png: 기존 와이파이를 제거한 교체용 차체.
- 첨다니_와이파이_신호약함.png: 두 곡선과 점의 속이 빈 파란색 테두리.
- 첨다니_와이파이_신호강함.png: 같은 무늬가 파란색으로 채워진 상태.
원래 차체에는 무늬가 그려져 있으므로 신호 레이어만 위에 덧씌우지 마세요. 새 차체로 교체한 뒤 신호를 별도 레이어로 올려야 약함 상태의 내부로 하늘색 차체가 보입니다. 전조등과 창문은 유지합니다.

2. 조립
투명 PNG의 실제 크기는 파츠정보.json에서 확인하세요. 생성 원본은1254×1254입니다.
신호는 원래 차체 아래 가운데, 양 전조등 사이에 위치해야 합니다. 원래 무늬의 대략적인 범위는 캔버스 x43.3~54.8%, y64.1~72.6%입니다. 이를 출발점으로 기존 기준형과 비교해 맞추세요.
생성된 신호는 원래 무늬보다 커졌고, 약함/강함 사이에도 미세한 윤곽 차이가 있을 수 있습니다. 그대로 교차 표시하며 위치가 고정됐다고 가정하지 마세요. 중심과 보이는 외곽 크기를 맞추고 상태 전환 시 튀거나 이중 테두리가 생기는지 확인하세요. 새 차체 역시 기존 조립 좌표와 비교해 필요한 보정값을 기록하세요.
신호는 차체에 종속시켜 이동·축소·기울기·공중제비를 함께 따라가게 합니다. 귀/안테나의 지연 반동을 신호에는 적용하지 않습니다.

3. 순차 점등
약함 이미지를 기본 레이어로 두고, 강함 이미지를 같은 위치에 겹칩니다.
강함 이미지를 ‘아래 점 / 안쪽 곡선 / 바깥 곡선’ 세 구역으로 마스크 처리해 각각 채울 수 있게 해 주세요. PNG 원본을 세 번 새로 생성할 필요는 없습니다.
단계는 다음과 같습니다.
0: 전체 테두리만.
1: 아래 점만 채움.
2: 점과 안쪽 곡선 채움.
3: 전부 채움.
두 상태는 같은 파란색 계열을 유지하고 광채, 그림자, 새 색상은 추가하지 않습니다. 불필요한 네온 효과 없이 단순한 그림체를 유지합니다.

4. 감정별 모션 제안
시간은 조정 가능한 초기값입니다. 무한 반복하지 말고 해당 동작 안에서 끝낸 뒤 기본 상태로 복귀해 주세요.

- 신나게 환영: 0→1→2→3을 단계당 약0.18초로 진행, 전부 켜진 채 약0.35초 유지. 필요하면 두 번까지만 반복. 차체가 펴지고 질끈 웃는 눈으로 바뀌는 시점에 시작합니다.
- 달려오기: 주기적인 반짝임은 넣지 않고, 접근 마지막 구간에서 아래에서 위로 한 번만 점등. 얼굴·바퀴·귀가 주로 움직이게 합니다.
- 공중제비와 착지: 도약 전0→3으로 충전하듯 점등, 회전 중에는 강함을 유지. 착지 때3→1로 잠깐 약해졌다가 약0.25초 후3으로 회복. 흔들림이 가라앉으면 기본 상태로 돌아갑니다.
- 당황·머뭇거림: 0→1→0, 잠깐 멈춘 뒤1→2→0으로 한 차례 헛기침하듯 점등. 눈은 기본을 유지하고 차체가 작게 갸웃합니다. 잦은 표정 교체는 하지 않습니다.
- 편안한 대기: 기본적으로 강함을 정지 표시합니다. 계속 깜빡이지 않습니다. 별도의 졸음 동작이 있을 때만 약함으로 바꾸고 천천히 복귀합니다.

로그인 성공 응원과 나중에 연결한다면 실제 인증 성공 시 한 번만 아래에서 위로 점등하고, 화면 전환을 기다리게 만들지 마세요. 이번 작업에서 인증 로직까지 변경할 필요는 없습니다.
이 무늬는 감정 표현입니다. 실제 인터넷 품질·서버 연결·로그인 진행률을 측정하는 표시로 연결하지 않습니다.
비밀번호 입력 키 종류·내용·개수에 따라 신호를 바꾸지 마세요.

5. 기존 연출 원칙
한 동작의 얼굴 표정은 가능하면2개, 최대3개를 유지합니다.
눈·눈썹은 같은 순간에 변경합니다. 와이파이는 추가 얼굴 표정 대신 감정을 보조하는 역할로 사용합니다.
슬로모션 환영 장면에서는 점등도 함께 느려지도록 장면 시간과 동기화해 주세요.
모션 줄이기 설정에서는 순차 점등/깜빡임을 생략하고 최종 상태만 표시합니다.

6. 검수 범위와 결과물
이번 검수는 교체용 차체 조립 → 신호0~3단계 → 환영 → 공중제비/착지 → 정렬 후 안정 상태까지입니다.
- 기존 무늬 잔상이 남지 않는지.
- 약함 이미지 내부가 투명해 차체색이 보이는지.
- 두 상태의 중심·크기·색이 일치하며 전환 시 튀지 않는지.
- 곡선의 중간이 잘리지 않고 단계별 마스크가 정확한지.
- 공중제비에서 차체와 신호가 함께 회전하는지.
- 환영 슬로모션과 점등이 함께 느려지는지.
- 종료/건너뛰기/재시작 시 타이머와 상태가 초기화되는지.
- 작은 크기에서도 신호가 전조등을 가리지 않고 알아볼 수 있는지.
위 항목별 통과/미확인/수정 필요를 적고, 정지 비교 화면과 짧은 재생 미리보기를 전달해 주세요. 실제 화면에서 확인하지 않은 항목을 완료로 표시하지 마세요.
