클로드 전달용 — 첨다니 파츠 조립 및 모션 검수

이번 범위
첨부한 첨다니 파츠 9개를 조립하고, 정면 달려오기·환영·왼쪽 공중제비·착지·최종 정렬까지 미리보기로 검수해 주세요. 이 ZIP은 생성된 파츠 초안이며, 픽셀 단위 정합과 실제 모션 조립을 완료한 패키지가 아닙니다. 기존 사이트 코드와 파츠 구조를 먼저 확인하고 반영해 주세요. 인증 로직 변경이나 운영 배포는 이번 범위에 포함하지 않습니다.

전체 콘티
1. 다섯 친구가 정면으로 우다다닥 달려옵니다. 옆모습 버스 탑승/하차 연출은 사용하지 않습니다.
2. 참고 환영 시안처럼 모입니다. 길통이 중앙, 티라 왼쪽 아래, 차로차로 오른쪽 아래, 도로덕 오른쪽 끝, 첨다니 오른쪽 위가 기본 관계입니다. 초록 캐릭터는 사용하지 않습니다.
3. 넘어질 듯 균형을 잡는 순간 아주 느린 움직임으로 전환합니다. 정지 화면으로 굳히지 않습니다. 티라는 ‘환영’, 도로덕은 ‘합니다!’ 팻말을 들고, 길통이는 팔을 벌려 인사합니다. 차로차로는 점프하며 귀를 파닥거립니다.
4. ‘환영합니다!’ 문구가 펼쳐지고, 작은 폭죽과 색종이가 뒤에서 터집니다. 겨울 고속도로 배경은 이 슬로모션 때만 등장합니다. 배경 외곽은 변이 부드럽게 휜 사각형과 점진적인 투명도로 처리하고, 캐릭터/문구는 선명하게 유지합니다. 울퉁불퉁한 구름 모양 가장자리는 피합니다.
5. 환영 인사를 마치고 정상 속도로 돌아옵니다. 배경·폭죽·큰 문구가 사라집니다.
6. 그 뒤 첨다니가 오른쪽 위에서 왼쪽으로 포물선을 그리며 반시계 방향 한 바퀴 공중제비를 돌아 왼쪽 끝에 착지합니다.
7. 첨다니–티라–길통이–차로차로–도로덕 순으로 정렬하고, 모두 작아져 하단으로 이동하며 로그인 화면이 나타납니다.
전체는 약 6~7초부터 조정하되 5초에 억지로 맞추지 않습니다. 장면별 임시 타이밍과 최종 실제 시간을 함께 적어 주세요.

첨다니 파츠
- 차체바탕: 창문, 중앙 기둥, 아래 파란 무늬, 전조등 포함. 눈·눈썹은 별도.
- 화면왼귀, 화면오른귀: 화면 기준 명명.
- 안테나: 줄기와 노란 공이 한 파츠입니다.
- 화면왼바퀴, 화면오른바퀴.
- 눈_기본: 두 점이 한 이미지.
- 눈_질끈웃음: > < 두 눈이 한 이미지.
- 눈썹_기본: 두 눈썹이 한 이미지.
입은 새로 만들지 않습니다. 아래쪽 파란 무늬와 전조등을 입/눈으로 바꾸거나 움직이지 마세요.

조립 확인과 알려진 보정 사항
파일의 실제 캔버스 크기는 함께 들어 있는 파츠정보.json을 기준으로 확인해 주세요. 1024 요청과 달리 생성 원본이 1254×1254일 수 있으므로 크기를 가정하지 마세요. 먼저 원본 좌표계를 통일한 뒤 표시 배율을 적용하세요.
파츠마다 생성 중 위치·크기 차이가 있습니다. 특히 안테나와 눈썹이 기본형보다 크고, 양쪽 귀와 바퀴도 서로 크기가 다를 수 있습니다. 같은 크기 캔버스라는 이유만으로 그대로 포개면 완성된다고 가정하지 마세요.
조립 기준형과 공식 기본형을 나란히 두고 확인하세요. 파츠의 실제 알파 영역을 기준으로 크기·위치·각도를 맞추고, 보정값을 데이터로 기록하세요. 눈과 눈썹을 지나치게 키우지 마세요. 기본 눈 중심의 기준은 캔버스 가로 약37.4%,60.4%, 세로 약48.4%이며, 눈썹은 세로 약40.4%입니다. 이 값은 출발점이며 기준형과 겹쳐 최종 확인해야 합니다.
몸통 뒤로 귀·안테나·바퀴를 배치하고 연결 끝이 충분히 가려지도록 하세요. 틈, 패임, 겹친 테두리, 잔상, 바퀴 잘림을 확인하세요. 생성 파츠의 윤곽을 과하게 찌그러뜨려 맞추지 말고 보정으로 해결되지 않는 부분은 별도로 보고하세요.

모션 구조
- 무대 위치/전체 크기 래퍼 → 공중제비 회전 그룹 → 차체 및 개별 파츠 구조로 나눠 이동, 전체 회전, 국소 반동이 충돌하지 않게 해 주세요.
- 정면 달려오기는 바퀴가 짧게 번갈아 움직이고, 차체가 작게 통통 오르내리는 방식입니다. 지그재그로 지나치게 흔들지 마세요.
- 공중제비는 조립된 첨다니 전체를 중심 근처 축으로 한 번 회전합니다. 파츠마다 각각 360도 돌리지 마세요. 발끝을 축으로 돌리거나 귀가 차체에서 떨어지는 현상을 막아 주세요.
- 귀와 안테나는 뒤늦게 따라오는 작은 반동을 주되 착지 뒤 빠르게 안정시킵니다. 기본 자세로 정확히 복귀해야 합니다.
- 한 동작의 표정은 최대3개, 가능하면2개입니다. 이번에는 기본/질끈웃음 두 눈만 사용해 충분히 표현합니다. 눈과 눈썹 상태를 바꿀 때는 같은 순간에 바꿔 주세요.
- 최종 정렬 후 첨다니의 보이는 키와 바퀴 바닥 높이가 다른 친구들과 자연스럽게 맞는지 확인하세요.

차로차로 크기 조절
기존 차로차로 PNG와 표정 파츠는 그대로 보관합니다. 조립된 캐릭터 최상위 그룹에 균일 배율을 적용해 전체 크기를 맞추세요. 눈·입·날개를 제각각 축소하거나 투명 여백을 잘라 좌표계를 바꾸지 마세요. 이미지 캔버스 크기만 비교하지 말고 실제 캐릭터가 차지하는 영역과 바닥선을 비교하세요. 변경 후 점프 높이, 날개 회전축, 화면 잘림을 다시 확인하세요. 기존 파츠 자체에 위치 오차가 발견될 경우만 해당 연결 위치를 별도로 보정합니다.

검수 결과물
1. 기본형과 파츠 조립형을 나란히 비교한 화면.
2. 정면 달려오기 → 느린 환영 → 왼쪽 공중제비 → 착지 → 최종 정렬을 확인할 영상/GIF 또는 재생 가능한 미리보기.
3. 파츠별 보정값, 실제 장면 시간, 해결하지 못한 문제 목록.
4. 작은 화면에서 귀/안테나가 잘리지 않고 로그인 입력 영역을 가리지 않는지 확인.
5. 초기화/재생 반복 시 위치·각도·표정 누적 없이 같은 결과가 나오는지 확인.
전체 콘티를 확인하되 이번 구현과 검수는 첨다니 중심으로 진행하고, 다른 캐릭터/기존 인증 동작은 필요한 범위만 연결해 주세요. 비밀번호 입력에는 키 종류·내용·길이에 따른 개별 반응을 넣지 말고, 입력 중에는 일정한 시선 회피 상태만 유지해 주세요. 로그인 성공 응원은 실제 인증 완료에 맞추고 다음 화면 전환을 지연시키지 마세요.
