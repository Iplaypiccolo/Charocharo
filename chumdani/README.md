# 첨다니 조립 검수 + 와이파이 감정 신호 (로그인 인트로 준비)

| 위치 | 내용 |
|---|---|
| `원본/` | 받은 파츠 9장·참고 이미지, `원본/와이파이추가/` 교체 차체·신호 2장. 수정하지 않음 |
| `검수본/` | 보정본(`_fix_log.json`). 신호 강함은 점/안쪽/바깥 세 장으로 나눔 |
| `chumdani.json` / `rig.json` | 캐릭터 파일 / 기준점·그룹 구조·동작별 신호 단계표 |
| `review.html` | 검수 미리보기(A 대기, B 달려오기, C 환영, D 당황, E 공중제비·착지·정렬) |

## 구조
무대 위치·크기 그룹(`rig`) → 공중제비 회전 그룹(`flip`, 차체 가운데 축) → 차체 → 귀·안테나·바퀴·신호·눈·눈썹.
신호: 약함(테두리) 위에 강함 점(`wifi1`)·안쪽(`wifi2`)·바깥(`wifi3`)을 겹쳐 투명도로 0~3단계. 모두 차체의 자식이라 함께 움직임. 귀·안테나 반동은 신호에 적용하지 않음.

## 보정
교체 차체는 그대로. 신호 2장은 원래 무늬에 맞춰 75%·위 13px. 안테나 62%·위 60px, 눈썹 각 50%, 오른귀 80%, 왼바퀴 102%, 질끈 눈 중심 맞춤.

## 원칙
신호는 감정 표시일 뿐 실제 통신·로그인 진행·키 입력과 연결하지 않음. 모션 줄이기에서는 순차 점등 없이 전부 켜진 상태만.
