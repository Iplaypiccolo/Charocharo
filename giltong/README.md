| 위치 | 내용 |

| `원본/` | 받은 그대로의 파츠 12장(1254×1254), 참고 이미지, 검수 요청서. 수정하지 않음 |

| `rig.json` | 배치·회전 기준점·잘라낸 그림의 원래 위치(x, y, w, h)와 원래 캔버스 크기 |

- 그림을 다시 받아야 하는 파츠는 없음.
- 팔은 35° 넘게 들면 큰 머리 뒤로 숨음 → 환영 인사는 24° 안팎. 참고 이미지처럼 크게 들려면 '인사용 팔' 그림이 따로 필요(선택).
- 다리는 55°까지 자연스럽지만 숨는 뿌리 여유가 적음 → 위로 60px 늘리면 더 안전(선택).
- 짙은 파란 로그인 배경에서는 남색 윤곽이 묻히는 편 → 전체 인트로에서 흰 외곽선이나 밝은 배경 검토.
