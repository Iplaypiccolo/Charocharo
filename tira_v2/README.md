## 구조
몸통 → 팻말+팔 그룹(`hold`: 팻말, 왼팔, 오른팔이 함께 움직임) → 눈·입 → 불꽃(입의 자식, 뿌리 449,553 고정).
겹침 순서: 꼬리·발 → 몸통 → 팻말 → 팔(손이 판 옆을 덮음) → 눈·입 → 불꽃.
